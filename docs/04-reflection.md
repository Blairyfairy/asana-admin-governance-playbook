# Reflection

**1. How will you implement this checklist in your role as an Asana administrator?**

I'll implement the checklist as a recurring Asana project, with each item as a task assigned to me and due on a set cadence: monthly license audits, a guest and access review at every engagement close, and a quarterly governance and security review. Each task will link to the Admin console path and a "done when" outcome, so I or a delegate admin can run it consistently. I'll also use the Insights tab to spot unusual activity between reviews.

**2. What challenges might you face when implementing these best practices in a real-world scenario, and how would you address them?**

The biggest challenge is that, as a freelancer, I have limited time and clients may resist stricter guest limits or view only licenses. I'll address this by automating reminders, explaining the security and cost benefits, and rolling out changes gradually. I'll also document every policy so settings don't drift over time.
